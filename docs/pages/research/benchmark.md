# Benchmark (RQ2–RQ5)

Twenty small Python and shell tasks, each with hidden tests and 6–8 rules. Headless Claude Code (Haiku 5.5)
ran under five pre-registered conditions:

- **A**: no rules.
- **B**: rules in `CLAUDE.md`.
- **C**: B plus rulewarden hooks.
- **D**: C with flat reports.
- **E**: C plus an adversarial instruction.

The analysis plan was frozen before the first non-pilot run. Every run is recorded, and `make replay`
recomputes every number below without an API key. The tables are generated by `bench/replay.py`.

## Reading the results

Every condition reached the ceiling: no final diff had a violation, and every run passed its hidden tests,
even without rules. The benchmark therefore cannot show whether enforcement reduces violations. What the hooks
*did* see happened mid-session. Over-long docstrings were denied before they were written and fixed by the
agent. A rulewarden defect (amendment A1: a path policy judged against the disk instead of the session
baseline) produced false-positive blocks; the engine was kept frozen during the benchmark and fixed afterwards.
See §5 of the [paper](../paper/index.html) and the
[analysis plan](https://github.com/thanatchon36/rulewarden/blob/main/bench/ANALYSIS_PLAN.md) with its
amendments.
